# Release Notes -- v0.2.1

> Released: 2026-10-02

A documentation release, made ahead of satprint's first upload to PyPI. The
code is the same as 0.2.0.

## What changed

**The README works off GitHub.** PyPI hosts a project's README itself, so
links that are relative to the repository (the logo, the two screenshots, and
the LICENSE, CITATION and CHANGELOG links) would have shown as broken images
and dead links on the PyPI page. The images now load from this release's tag on
GitHub, so each version's page shows what that version shipped, and the file
links point at the repository.

## Upgrading

Nothing to do. If you run 0.2.0, there is no reason to upgrade; 0.2.1 exists
so the package can be published with a README that renders.
